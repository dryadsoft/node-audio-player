# 화면별 관리 모달과 공통 센터 관리

2026-09-12 로컬 구현·검증. API·DB 스키마·필기 형식 변경 없음.

## 사용 흐름

- **출석부**: 상단 수업 표시를 누르면 오른쪽 선택 패널을 연다. 연도·학기 → 센터 → 등록된 요일 → 수업시간·교시 순으로 선택한다. 수업을 누르면 첫 유효 페이지를 열고 패널을 닫는다. 페이지가 없으면 기존 줄노트·사진 추가 화면을 표시한다.
- **출석부 관리**: 선택 패널의 관리 버튼에서 중앙 모달을 연다. 센터·요일, 수업시간·교시, 페이지 탭에서 등록·변경·순서 변경·삭제·복구를 수행한다. 요일·교시 이름은 저장 버튼으로 확정한다. 휴지통·사용 중지 센터 포함과 오프라인 저장 대상 학기 지정도 여기서 한다.
- **계획서 관리**: 본 화면의 검색·목록·미리보기·DOCX 다운로드는 유지한다. 관리 버튼에서 신규·수정·전체 복사를 넓은 모달로 연다. 센터 관리와 특정 주차 가져오기는 같은 모달 내부에서 왕복하며 초안을 보존한다. 변경한 초안 취소에는 폐기 확인이 필요하다.
- **수업노트 관리**: 원본 생성, 기존 계획서 가져오기, 12주 교체, 원본 삭제를 모달에 모은다. 수업명·수업내용 직접 편집과 필기는 본 화면에 유지한다. 저장 상태·동기화 재시도·충돌 해결·복구 내보내기는 기존 위치를 유지한다.
- **공통 센터 관리**: 세 관리 모달에서 동일한 센터 등록·이름 변경·사용 중지·다시 사용 기능을 연다. 중첩 팝업 없이 이전 관리 화면으로 돌아간다.

## 센터 상태와 기록 보존

- `LessonLocation.active`는 센터 전체에 적용되며 특정 학기·요일 등록의 휴지통 여부와 독립적이다.
- 일반 센터 선택·신규 등록 대상·계획서 가져오기 목록은 사용 중지 센터를 제외한다. 관리 목록은 사용 상태 필터로 전체·사용 중·사용 중지를 조회한다.
- 기존 계획서 전체 조회와 공통 수업노트 원본 목록은 유지한다. 기존 계획서 수정에서는 현재 사용 중지 센터를 유지할 수 있지만 신규·복사본은 사용 중인 센터를 선택해야 한다.
- 출석부 관리의 사용 중지 센터 포함으로 과거 기록을 조회한다. 현재 작성 중인 센터가 사용 중지돼도 캔버스와 입력을 유지한다. 새 진입 시에는 사용 중인 센터를 초기 선택한다.
- 센터 변경 후 React Query 목록·계획서와 모든 저장된 출석부 학기의 센터 정보를 갱신한다. IndexedDB의 사진·페이지·미전송 기록은 변경하지 않는다. 오프라인에서는 저장된 센터 상태를 사용한다.
- 센터 사용 중지는 기록을 삭제하지 않는다. 출석부 휴지통은 기존 복구 정책을 유지한다. 수업노트 원본 삭제는 연결된 계획서 내용을 보존·분리하지만 공통 원본 필기는 영구 삭제하므로 기존 확인 절차를 유지한다.

브라우저 확인은 임시 DB를 사용하는 `client/scripts/attendance-preview.mjs`로 수행했다. 운영 데이터는 변경하지 않았다. 미리보기 실행 중 build 폴더를 교체하면 파일 읽기 경쟁으로 미리보기 서버가 종료될 수 있어, 최종 빌드는 서버를 중지한 뒤 실행했다. 초기 센터 자동 선택 보완은 최종 회귀 테스트로 검증했다.

실제 iPad/Pencil, 설치된 PWA와 인증된 운영 화면은 미검증이다. 이번 변경의 커밋·푸시·운영 배포는 수행하지 않았다.
